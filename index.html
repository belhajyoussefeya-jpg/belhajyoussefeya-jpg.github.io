Q.02 Votre plus grande réalisation ?

Talk2Hire — l'IA et de vrais recruteurs, réunis sur une seule plateforme.

« Hire starts here. »

Application web de prédiction du risque de bugs dans des projets Java : à partir des métriques orientées objet d'une classe, le modèle estime son niveau de risque et signale les « hotspots » à prioriser pour les équipes QA.

Interface web
Intégration du modèle : saisie des métriques, score et probabilités affichés.
Java
Domaine cible : les classes des projets analysés.
